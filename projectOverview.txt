The Problem: During natural disasters, coordinating relief, tracking weather, finding safe evacuation routes, and organizing rescues is chaotic. Target Users: Local community members (Regular Users / Citizens) and Relief Organizers (Admin Coordinators).

API 1 (Weather): Open-Meteo API (100% Free) – To show live weather metrics (temperature, rainfall, wind) and real-time storm hazard advisories for pinned coordinates.
API 2 (Map & Geocoding): Leaflet.js + OpenStreetMap & Nominatim (100% Free) – Interactive geospatial map with landmark search, GPS locate, and reverse-geocoded click-to-drop emergency pins.
API 3 (AI): Google Gemini API (Free tier) – Users submit unstructured emergency descriptions, and Gemini automatically categorizes them (e.g., "Medical", "Flood", "Fire"), determines urgency, and extracts resource needs.
API 4 (News): GNews API & Meteorological RSS Wire (Free) – Pulls in real-time disaster news headlines and bulletins.
API 5 (Routing & Evacuation): OSRM / Open Source Routing Machine (100% Free) – Calculates turn-by-turn safe road evacuation routes, road distance (km), and driving/walking travel times from any disaster point or dropped pin to the nearest evacuation shelter.

CRUD Module: Users can Create, Read, Update, and Delete "Incident Reports" with live database synchronization.
Admin Dashboard: Shows KPI metrics, disaster triage charts, live evacuation shelter occupancies, and allows admins to resolve or delete false reports.

Why it scores high: It tackles a highly meaningful real-world problem (10/10 for Problem Solving) and geospatial mapping + AI categorization + live road evacuation routing looks incredibly advanced (15/15 for Technical Complexity), yet runs with 100% free APIs and zero credential bottlenecks.
